# cargo-gamma-attrs

Inert attribute macros for suppressing mutations generated by
[`cargo-gamma`](https://github.com/geeknoid/cargo-gamma).

```rust
#[gamma::skip]
fn hand_verified(x: u32) -> u32 { x + 1 }

#[gamma::skip(arith, reason = "fixed-point math, checked by proptest")]
fn scaled(a: i64, b: i64) -> i64 { a * b / 1000 }
```

Every macro in this crate expands to the annotated item unchanged. The attributes exist so
that cargo-gamma can see them, and so that a typo in a selector list is a compile error in
your crate rather than a silently ineffective suppression.
